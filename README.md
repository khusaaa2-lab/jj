# Serenity International School

Кинематографичный сайт школы в существующем проекте jj: видеокампус с перемещением и масштабом, 13 мест, десять отдельных панорам, RU/EN, экскурсия, звук по желанию и локальные демо. Последнее полное задание: reference/cinematic-update/BRIEF.md. Реализация и анализ референсов: [docs/CINEMATIC-UPDATE.md](docs/CINEMATIC-UPDATE.md).

## Запуск

Node.js 22.12 или новее.

```sh
npm ci
npm run dev                # Vite, 5173
npm run build              # полноценный dist
npm run preview            # просмотр production, 4173
npm run check              # проверки данных, состояния, панорам и границ видеокарты
npm run check:browser      # Chromium: комнаты, видео, жесты, RU/EN, демо и адаптивность
npm run capture:review     # скриншоты настоящей production-страницы (preview должен работать)
npm run package:production # ZIP всей сборки + автономный Node-сервер
node scripts/verify-production.mjs
npm run package:source     # редактируемые исходники + исходные медиа и BRIEF
npm run package:preview    # дополнительный HTML-preview с отдельным MP4
```

Браузерные тесты используют /usr/bin/chromium или CHROMIUM_PATH. Артефакты по умолчанию: /workspace/outputs/serenity-cinematic; для упаковки задайте SERENITY_OUTPUT. Это файлы задачи, не публичная публикация. Код приложения в src; исходный Vite HTML — src/index.vite.template. Корневой index.html автоматически генерируется для файлового предпросмотра; не редактируйте его вручную. Vite подставляет исходный шаблон при dev/build. В архиве исходников index.html является редактируемой копией этого шаблона.

## Готовые архивы и просмотр

**Serenity-production.zip** содержит весь dist, видео, постер, изображения комнат, шрифты, serve.mjs и START-HERE.txt. После распаковки: `node serve.mjs`, затем открыть http://localhost:5173 на своём компьютере. Установка npm-пакетов для этой сборки не нужна. Сервер поддерживает video/mp4, byte ranges и прямые ссылки на страницы. Не открывайте Vite production index.html как отдельный текстовый файл: браузеру нужны соседние ассеты и HTTP-сервер. Для обновления существующего Site передайте весь каталог сборки; требуется размещение в корне сайта и SPA fallback.

**Serenity-source.zip** содержит редактируемые модули, lockfile, тесты, скрипты, инструкции, runtime-ассеты и оригинальные A/B/C/PNG/KINETIC в reference/cinematic-update. node_modules, .git, .env и старые ZIP не включены.

Дополнительный **preview/Serenity-Preview.html** встраивает JS/CSS/шрифты/изображения, использует hash-маршруты и сохраняет рядом отдельный media/campus/campus-A.mp4. Нужна сохранённая структура папок; видео не превращается в огромную base64-строку. При запрете/отсутствии видео работают статичный кадр и все комнаты. Это уже не автономный однофайловый видеоархив. Алиас package:single сохранён для совместимости и запускает тот же генератор. Проверка: node scripts/verify-cinematic-preview.mjs. Управляемый Chromium запрещает file://, поэтому точные байты HTML проверяются через локальный HTTP и в изолированном iframe. Регистрация карточки Site через API здесь недоступна; этот тест не означает проверку интерфейса самой задачи.

## Управление и доступность

- Перетаскивание перемещает видеокарту; колесо, +/− и pinch меняют масштаб. Home / кнопка полного обзора показывают весь кампус. Стрелки перемещают вид, когда карта в фокусе.
- 11 наружных меток соответствуют 13 местам. Игровая гостиная находится на нижнем уровне технологического корпуса; тихая комната — внутри учебного. Доступны и через список, и через панель своего здания.
- Выбор открывает описание справа; на телефоне — нижнюю прокручиваемую панель. Библиотека встроена в гору справа сверху. Крыши не открываются.
- Десять перспективных панорам сохраняют ограниченное перемещение, три детали комнаты, клавиатурное управление и возврат в прежний вид кампуса. Escape закрывает помещение/выбор; экскурсия продолжает текущую остановку.
- Пауза видео независима от звука. Аудиодорожка исходного ролика удалена. Процедурная музыка и вода включаются только явным действием; есть громкость/выключение. Невидимая вкладка приостанавливает звук и видео.
- Reduced motion показывает постер до явного запуска MP4. Ошибка видео оставляет метки и предлагает повторить загрузку; независимая статичная карта и полный список сохраняются. WebGL не требуется.
- Шесть маршрутов: /, /campus, /learning, /life, /events, /project. Старые ссылки view=3d совместимы с новым видом.

## Медиа и честные ограничения

Выбран campus-loop-A.mp4: **8 секунд, 1280×720, 24 fps**, фиксированный ракурс. Runtime H.264, faststart, без аудио. В конце — 0,35 с растворения к постеру из первого кадра для более мягкого повтора. Нет свободного орбитального вращения, 4K или сферического 360°-обзора. Масштаб ограничен; исходная детализация 720p заметна при приближении.

Все три видео и весь KINETIC-референс сохранены без изменений. Для повторной подготовки runtime: `python scripts/prepare-campus-media.py` (Pillow, ffmpeg). Выборочная оценка устойчивости: `python scripts/review-campus-media.py` (numpy, scipy, ffmpeg). Оба скрипта не нужны для обычной сборки: готовые ассеты включены.

Происхождение комнат: public/media/asset-map.json. Происхождение видео/постера: public/media/campus/manifest.json. Десять комнат: главный холл, библиотека, учебная студия, лаборатория, две разные столовые, игровая, мастерская, тихая комната и резиденция. Старые Three.js исходники и captures сохранены как исторические материалы; текущий интерфейс их не использует.

Школьный день 09:00–17:00, свободный час 12:00–13:00. События длятся две недели. Голоса, брони, избранное и черновики хранятся локально в прежнем serenity:v1; язык — serenity:language:v1. При недоступном хранилище используется память. Реальных отправок/приёма/общих результатов нет. Домен и Telegram не подключены.

DM Sans и Libre Caslon Display локальные, лицензии SIL OFL в public/fonts. Новый Site, домен, публичный сервис и платная генерация в рамках обновления не создавались.
