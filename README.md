# Serenity International School

Development workspace for the My Dream School website.

This repository contains a dependency-free starting environment, project guidance and school data. The complete website is the next development task.

## Run

Use Node.js 22 or newer.

```sh
npm ci --ignore-scripts
npm run check
npm run dev
```

The development server uses port 5173 by default and binds to 0.0.0.0. Set PORT and HOST to override them.

## Read first

- AGENTS.md: instructions for Codex
- docs/PROJECT.md: agreed product brief
- docs/CODEX_SETUP.md: cloud environment setup
- public/data/places.json: canonical campus place IDs

No API keys, paid services or Telegram credentials are required for this starting environment.
