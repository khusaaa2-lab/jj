# Serenity International School

Текущая версия — настоящая пространственная модель кампуса по aerial-референсу пользователя. Three.js строит объёмы, закрытые кровли, башню, площадь, два уровня tech, отдельные столовые, стадион и библиотеку в скальном склоне. Ракурс меняется через orbit/pan/zoom. Это ручная архитектурная интерпретация одного изображения, не фотограмметрия; невидимые стороны и размеры приблизительны.

Сохранены 13 канонических мест, 10 разных панорам, RU/EN, экскурсия, возвращение в прежний вид, звук по желанию, доступный список и локальные демо. Клик открывает описание справа, на мобильном — нижнюю панель. Игры расположены в нижнем уровне tech, тихая комната — в учебном корпусе. Крыши не раскрываются.

## Запуск и проверка

Node.js 22.12+:

```sh
npm ci
npm run dev
npm run check
npm run build
npm run preview
npm run check:browser -- --max-failures=1
node scripts/verify-dist.mjs
```

`dist/` включён в ветку со всеми runtime-ассетами. Его можно перенести целиком в существующий Site без генерации модели или ассетов. Нужны HTTP и SPA fallback для шести маршрутов: `/`, `/campus`, `/learning`, `/life`, `/events`, `/project`. Исходный HTML не является автономным файловым предпросмотром; Vite использует `src/index.vite.template`.

`npm run check` проверяет данные, состояния, панорамы и геометрию, включая лучи выбора башни, замкнутость кровель, кадрирование и ось стадиона. Браузерная проверка требует Chromium с работающей штатной sandbox; защиты не отключаются. В текущей среде безопасный запуск заблокирован. В пользовательском Sites preview WebGL также отключён. Полного браузерного 3D QA нет; границы проверки записаны в [docs/qa/FINAL-REVIEW.md](docs/qa/FINAL-REVIEW.md).

## Режимы и управление

- 3D: перетаскивание меняет ракурс; правая кнопка или Shift+стрелки перемещают; колесо, +/− и два пальца меняют масштаб; Home возвращает обзор. Снаружи canvas страница прокручивается.
- После ошибки WebGL автоматически открывается 2D-карта с постоянным пояснением. Ручной выбор 2D не показывает ошибку. Нижняя подпись различает 3D, карту и интерьер.
- Все десять панорам работают без WebGL: ограниченное перемещение без сферического искажения, три детали, клавиатура, возврат в выбранное здание и текущую остановку экскурсии.
- Аудио запускается только пользователем. Reduced motion отключает полёты камеры. Голоса, брони, избранное и черновики — локальные демо без отправки на сервер.

## Редактируемая архитектура

- `src/reference-model.js` — общая геометрия, материалы, освещение форм через объёмы, скрытые hit volumes и пакетирование повторяющихся деталей.
- `src/reference-layout.js` — расположение корпусов, высоты, метки и пешеходные пути.
- `src/reference-mountains.js` — отдельная геометрия горных хребтов со снегом.
- `src/reference-campus.js` — WebGL renderer, свет, тени, камера, выбор, DOM-метки, жизненный цикл.
- `src/main.js`, `pages.js`, `styles.css` — существующий интерфейс, состояния и fallback.
- `src/content.js`, `panorama.js`, `public/media/asset-map.json` — десять исходных панорам и их происхождение.

Геометрические доказательства: `docs/qa/01-reference-angle.png`, `02-second-angle.png`, два крупных плана, GLB и manifest. PNG получены из точных mesh-данных отдельным EGL-рендерером с независимым шейдером. Это не скриншоты Three.js WebGL и не оценка браузерных PBR-материалов.

Для повторной выгрузки:

```sh
node scripts/export-reference-geometry.mjs
# Python: numpy, Pillow, moderngl (standalone EGL)
python3 scripts/render-reference-evidence.py
```

Выход по умолчанию: `/workspace/outputs/serenity-reference-3d/geometry`; можно задать `SERENITY_3D_OUTPUT`. Временные vertex buffers не входят в Git. Экспортированный GLB содержит настоящие meshes, экземпляры и PBR-материалы, без фотографии кампуса как плоскости.
